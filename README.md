# HR Dashboard - Power BI

## 📊 Project Overview
This dashboard provides insights into employee data including attrition, salary, and department analysis.

## 🔧 Tools Used
- Power BI
- DAX

## 📌 Key Insights
- Attrition rate by department
- Gender distribution
- Salary trends
